4. Keys Identification in each table. (Primary keys and foreign keys)
Primary Keys (PK)
 Branch --&gt; BranchID
 Customer --&gt; CustomerID
 Account --&gt; AccountNo
 Transaction --&gt; TransactionID
 Loan --&gt; LoanID
 Account_Holder --&gt; (CustomerID, AccountNo) (Composite Key)
Foreign Keys (FK)
 Account --&gt; BranchID --&gt; Branch(BranchID)
 Account_Holder --&gt;
o CustomerID --&gt; Customer(CustomerID)
o AccountNo --&gt; Account(AccountNo)
 Transaction --&gt; AccountNo --&gt; Account(AccountNo)
 Loan --&gt;
o CustomerID --&gt; Customer(CustomerID)
o BranchID --&gt; Branch(BranchID)

5. Relationships Between Tables (One-to-Many / Many-to-Many)
1. Branch --&gt; Account
 Type: One-to-Many (1:N)
 One branch can have many accounts
 One account belongs to one branch

2. Branch --&gt; Loan
 Type: One-to-Many (1:N)
 One branch offers many loans

3. Customer ↔ Account
 Type: Many-to-Many (M:N)
 Implemented using Account_Holder table
 A customer can have multiple accounts
 An account can be jointly held by multiple customers

4. Account --&gt; Transaction
 Type: One-to-Many (1:N)
 One account can have many transactions

5. Customer --&gt; Loan
 Type: One-to-Many (1:N)
 One customer can take multiple loans

Instructions for Students
● Minimum 3 tables
● Must include:
o Primary Keys
o Foreign Keys
● Proper relationships are compulsory

6. Table Creation Commands
Write the SQL CREATE TABLE commands for all tables.
Table 1: Branch
CREATE TABLE Branch (
BranchID INT PRIMARY KEY,

Name VARCHAR(50) NOT NULL,
Address VARCHAR(100)
);
Table 2: Customers
CREATE TABLE Customers (
CustomerID INT PRIMARY KEY,
Name VARCHAR(30) NOT NULL,
Phone VARCHAR(15),
Address VARCHAR(100)
);
Table 3: Accounts
CREATE TABLE Accounts (
AccountNo INT PRIMARY KEY,
AccountType VARCHAR(20),
Balance DECIMAL(10,2) CHECK (Balance &gt;= 0),
BranchID INT,
OpeningDate DATE,
FOREIGN KEY (BranchID) REFERENCES Branch(BranchID)
);
ALTER TABLE Accounts
ADD CONSTRAINT chk_account_type
CHECK (AccountType IN (&#39;Savings&#39;,&#39;Current&#39;));
Table 4: Account_holders
CREATE TABLE Account_Holders (
CustomerID INT,
AccountNo INT,
PRIMARY KEY (CustomerID, AccountNo),
FOREIGN KEY (CustomerID) REFERENCES Customers(CustomerID),
FOREIGN KEY (AccountNo) REFERENCES Accounts(AccountNo)

);
Table 5: Transactions
CREATE TABLE Transactions (
TransactionID INT PRIMARY KEY,
AccountNo INT,
Type VARCHAR(20) CHECK (Type IN (&#39;Deposit&#39;,&#39;Withdraw&#39;,&#39;Transfer&#39;)),
Amount DECIMAL(10,2) CHECK (Amount &gt; 0),
Date DATE,
FOREIGN KEY (AccountNo) REFERENCES Accounts(AccountNo)
);
Table 6: Loans
CREATE TABLE Loans (
LoanID INT PRIMARY KEY,
LoanType VARCHAR(30),
Amount DECIMAL(10,2),
CustomerID INT,
BranchID INT,
InterestRate DECIMAL(5,2),
FOREIGN KEY (CustomerID) REFERENCES Customers(CustomerID),
FOREIGN KEY (BranchID) REFERENCES Branch(BranchID)
);
